# AgentDirectedGRN

Single-cell gene regulatory network inference run end to end by an AI coding agent, directed by a single versioned prompt file. The worked example infers GRNBoost2 co-expression networks for three cell types from a published sorghum root single-nucleus RNA-seq atlas.

The primary artifact here is `prompt.md`. The scripts in `scripts/` were written by the agent at run time and are included for reference, the agent may write different code on a different run.

---

## Contents

```
prompt.md                 The specification, exactly as run
environment.yml           Pinned conda environment
scripts/                  Written by the agent (00-06)
Sbi_RTx430_TF_list.txt    1,827 sorghum RTx430 transcription factors
figures/                  Output figures
run_log.md                Versions, job IDs, runtimes, deviations
```

## Inputs

Two of the three inputs are third-party and are not redistributed here.

**1. Expression atlas** — GEO accession [GSE297576](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE297576), file `GSE297576_seurat_object.bicolor_root_atlas.RDS` (1,314,285,536 bytes; 19,316 nuclei, 27 cell types, RTx430 gene identifiers).

Download with resumable transfer, this file fails partway often, and a truncated copy looks fine until R fails to parse it:

```bash
curl -L -C "-" --retry 30 --retry-delay 5 --retry-all-errors \
  -o GSE297576_seurat_object.bicolor_root_atlas.RDS \
  "https://www.ncbi.nlm.nih.gov/geo/download/?acc=GSE297576&format=file&file=GSE297576%5Fseurat%5Fobject%2Ebicolor%5Froot%5Fatlas%2ERDS"
```

Check the byte count afterwards.

**2. Marker genes** — supplementary file `41477_2025_2047_MOESM3_ESM.xlsx`, sheet `TableS10.sorghum_lit_markers`, from Baumgart et al. (2025) *Nature Plants* 11:1514–1527, [doi:10.1038/s41477-025-02047-0](https://doi.org/10.1038/s41477-025-02047-0). Available from the article's supplementary information (institutional access may be required).

**3. Transcription factor list** — `Sbi_RTx430_TF_list.txt`, included in this repository. Generated by submitting the RTx430 primary-transcript proteome (34,601 sequences) to the [PlantTFDB prediction server](https://planttfdb.gao-lab.org/prediction.php).

This list was generated rather than downloaded because the expression matrix uses RTx430 identifiers (`SbiRTX430.*`) while the precomputed PlantTFDB *Sorghum bicolor* list uses BTx623 identifiers (`Sobic.*`). The two intersect at zero genes, and they are not interconvertible by string manipulation, `SbiRTX430.01G002500` is not the same gene as `Sobic.01G002500`.

Place all three files in `data/raw/`.

## What you need

A Linux system with a job scheduler. The inference step must run on a compute node, not a login node. This example used Virginia Tech's ARC TinkerCliffs (SLURM): one node, 64 cores, 64 GB, and under 7 minutes per cell type.

The pipeline does not work on Windows, see Note 6 of the chapter.

## Setup

```bash
git clone https://github.com/mchaudhary22/AgentDirectedGRN.git
cd AgentDirectedGRN
mkdir -p data/raw
# put the three input files in data/raw/
# the agent creates data/processed/, results/, figures/, and logs/ as it needs them

module load Miniconda3/25.11.1-1          # your system's module name will differ
conda env create -f environment.yml -p ~/.conda/envs/grn   # mamba env create also works and is faster
conda activate ~/.conda/envs/grn
```

Verify the environment before running anything expensive. This takes seconds and catches two of the three known dependency problems:

```bash
python scripts/01_smoke_test_grnboost2.py     # must print 95 edges
```

## Edit `prompt.md` before running

If you are on ARC TinkerCliffs and using this same dataset, change only two things: the project path, so the agent writes into your own directory rather than ours, and the SLURM account in Step 04 if your allocation differs. Everything else: module names, partition, QOS, and all expected counts, is already correct for you. Skip the table below; it applies to a different cluster or a different dataset.`prompt.md` is the file as used on ARC TinkerCliffs. Change these before running it anywhere else:

| Section | What to change |
|---|---|
| Cluster rules, Step 00 | Module names, partition, QOS, account, project path |
| Step 04 | Cores, memory, wall time, `n_workers` |
| Inputs | Input filenames and species |
| Fixed parameters | Cell type column, doublet column and value, assay name, target cell types |
| Fixed parameters | **Every expected count** — these are properties of this dataset, not settings |

The expected counts are the mechanism by which the agent detects its own errors, so leaving ours in place with different data is worse than removing them. Derive your own first: load the object read-only, report the assays and dimensions, count nuclei per cell type, count singlets, and intersect the TF list with the matrix at several detection thresholds. Write those numbers into the prompt.

## Run

Point the agent at the file rather than pasting its contents:

```
Read prompt.md and execute it. Start with Step 00 and stop after Step 01
so I can check the intermediate outputs before the inference run.
```

The prompt has stop points after environment reconnaissance, environment build, and regulator preparation. Check the reported values against your own at each one, then tell the agent to continue.

The inference step is submitted to the scheduler by the agent, not run interactively. Keep that instruction in the prompt when you adapt it, an agent will otherwise run the job wherever it currently is, which on most clusters means a login node.

## Expected output

With this dataset:

| Stage | Value |
|---|---|
| Nuclei, before / after singlet filtering | 19,316 / 14,792 |
| Features, RNA assay | 25,464 (default assay is SCT, with 23,974 — use RNA explicitly) |
| TFs: annotated / in matrix / after threshold | 1,827 / 1,370 / 1,022 |
| Target cell types | exodermis 315, dividing cells 801, mature-endodermis 282 |

Files produced:

```
data/processed/root_singlets.h5ad          14,792 x 25,464, cells x genes
data/processed/regulators.txt              1,022 TFs
results/grnboost2_edges_<celltype>.csv     1.25-1.56M edges each
results/selected_tfs_<celltype>.csv        top 10 TFs per cell type
figures/                                   4 figures
```

Nuclei and TF counts are deterministic and should match exactly. Edge counts and importance values will match only with the same seed and the same package versions, GRNBoost2 is stochastic, and the agent may write different code on a different run.
